# Changelog

All notable changes to NOMAD LOG will be documented here.

## [Unreleased]

## [1.0.0] — 2026-03-14

### Added
- LOG tab: spot name autocomplete from previous entries
- LOG tab: GPS pin via browser Geolocation API with live map preview
- LOG tab: manual coordinate entry (`lat, lng`)
- LOG tab: spot type selector (Walmart, Church, Forest, etc.)
- LOG tab: 1–5 star rating
- LOG tab: positive / negative / conditions tag grid
- LOG tab: free-form notes textarea
- YT tab: shot-list checklist (session-scoped, resets on reload)
- JOURNAL tab: daily journal entries
- MAP tab: Leaflet map with pins for all logged spots, dark tile theme
- STATS tab: summary cards and tag frequency breakdown
- Export / import JSON backup
- Full dark terminal aesthetic (Teko + IBM Plex Sans + Share Tech Mono)
- Responsive layout, mobile-friendly
- Toast notifications
- `localStorage` persistence — no server required
